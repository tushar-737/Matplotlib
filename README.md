# 📊 Matplotlib for Data Science

This repository contains my learning journey and hands-on practice with Matplotlib, one of the most important Python libraries for Data Visualization in Data Science.

## 🚀 About

Matplotlib is a powerful visualization library used to create:

- Line Charts
- Bar Charts
- Histograms
- Scatter Plots
- Pie Charts
- Subplots
- Custom Styling & Formatting
- Data Visualization for Analysis

This repository includes examples, practice notebooks, and visualization projects that helped me understand how to present data effectively.
